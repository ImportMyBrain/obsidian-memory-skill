# 工作区指令示例

## Obsidian 记忆优先（每轮强制 · 分级检索 v2）

会话只加载一次 `obsidian-memory` skill，之后复用。每轮回答前分级处理：

1. **先读小抄**：`.memory/MEMORY_DIGEST.md`（本会话读过且没重建就复用）。
2. **小抄不够**：跑 `memory-search.mjs` 查索引，只看 top 3–5 条摘要。
3. **有候选**：读候选笔记前 60–80 行，或关键词附近的 ±20 行。
4. **仍不够**：才读整篇，最多 1–2 篇，每篇 ≤8 KB。

- 不要全库 grep；不要每轮重复读小抄 / 重复加载 skill；同一话题追问复用上一轮结果。
- 冷归档（对话记录、历史快照等）默认不参与；只有用户问“之前聊过 / 上次说”才查。
- 小抄缺失 / 超过 24h / 写回笔记后，跑一次 `memory-build.mjs` 重建。
- 没查到相关记忆：用一句话说明，然后正常回答，不要编造。

> 用法：把上面规则加到工作区根目录的 `AGENTS.md`。
> 全局指令（如 `~/.dsh/AGENTS.md`）会影响这台机器上的所有会话；如果还有群聊机器人 / 其他 agent，建议只用工作区级 `AGENTS.md`。

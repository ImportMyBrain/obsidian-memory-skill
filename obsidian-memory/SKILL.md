# Obsidian 记忆优先 · v2 分级检索（DSH 版）

## 0. 本机配置（安装后先改这里）

- `VAULT`：`__VAULT_PATH__` — Obsidian 库根目录，例如 `D:\Obsidian\MyVault`
- `MEMORY_DIR`：`<VAULT>/.memory` — 小抄 / 索引输出目录（默认）
- `ARCHIVE_DIRS`：冷数据目录（相对 `VAULT`，可多个；可选），例如 `Chats`、`Archive`
- `FALLBACK_MEMORY`：工作区记忆摘要文件（可选），例如 `MEMORY.md`

> 如果 `VAULT` 还是占位符：先向用户确认库路径，补全本段配置，再开始检索。

## 1. 每轮流程（Level 0 → 3，分级处理）

**Level 0 · 先看小抄**
- `read` `MEMORY_DIR/MEMORY_DIGEST.md`（约 2–3 KB：入口、个人偏好、目标、当前项目、最近更新）。
- 本会话已读过、且期间没有重建 → 直接复用，不要重复读。
- 小抄缺失 / 超过 24 小时 / 本轮写回了笔记 → 运行一次重建（见第 3 节），再读。

**Level 1 · 小抄不够，查索引**
- 用脚本检索索引（只返回 top 3–5 条摘要）：
  `node "<skill base>/scripts/memory-search.mjs" --vault "<VAULT>" --query "关键词1 关键词2" --top 5`
- 2~6 个关键词；只看返回的 title / path / date / summary。
- 用户问“之前聊过 / 上次说”时，加 `--include-cold` 查归档；其他情况默认排除冷数据。

**Level 2 · 有候选，读原文片段**
- `read` 候选笔记前 60~80 行（frontmatter + 开头）。
- 需要具体内容时：先 `grep` 该文件定位关键词，再 `read` 命中行前后各 20 行。
- 长文（>10 KB）不要直接全文读。

**Level 3 · 仍不够，读整篇**
- 最多 1~2 篇，每篇 ≤8 KB；只在用户明确要细节、或小抄+索引+片段仍不足时使用。
- 冷归档（历史对话记录等）不做整篇读，除非用户明确要求。

- 同一话题追问可复用上一轮结果；出现新实体 / 新主题才重新查。
- 没查到就一句话说明，然后正常回答；绝不编造记忆。

## 2. 预算（硬限制）

- 小抄 ≤3 KB；索引检索输出 ≤2 KB；片段 ≤1.5 KB/篇；整篇 ≤2 篇。
- 单轮记忆上下文总量建议 ≤8 KB；超预算就基于已读信息回答，或问用户是否细查。
- 不要每轮重复加载 skill；不要每轮重复读小抄；不要全库 grep（先查索引）。

## 3. 重建小抄 / 索引

小抄缺失、超过 24 小时，或本轮写回了笔记时运行一次：

```bash
node "<skill base>/scripts/memory-build.mjs" --vault "<VAULT>" --archive "Chats" --archive "Archive"
```

- 输出：`<VAULT>/.memory/MEMORY_DIGEST.md`、`MEMORY_INDEX.md`、`index.json`。
- 会话首次回答前检查一次即可，不必每轮重建。
- 归档 / 历史快照目录用 `--archive` 传入，会自动标记为 cold（默认不参与小抄和检索）。

## 4. 判断与整合

- 直接相关（必须用）/ 背景相关（调整语气、深度、优先级）/ 历史快照（只补充）/ 无关（跳过）。
- 冲突以更新时间更晚的主笔记为准，回答里说明依据。
- 引用来源与日期；区分“记录里的事实”和“我的推断”。
- 敏感信息（财务、证件、账号、健康、家庭等）只在必要相关时提。
- 没查到：一句话“Obsidian 里没查到相关记录”，然后正常回答。

## 5. 写回（有新信息才做）

- 新事实 / 进展 / 偏好变化：更新 `PROFILE_DIR` 下对应主笔记（保留结构、更新 `updated`），补 `[[双链]]`；没有新信息就不写。
- 写回后重建一次小抄 / 索引（第 3 节）。
- 不覆盖历史快照；不写账号密码 / 令牌。
- 对话原文如果由后台自动归档，不需要在本 skill 里手抄；只提炼新事实写回主笔记。

## 6. 隐私与安全

- 只读本地 Markdown，不上传任何内容；检索结果只用于本次回答。
- 不主动读取 `.obsidian/`、系统目录和附件二进制；不把库里的隐私内容带进群聊或第三方会话。
- 只用于用户本人的会话；面向群聊 / 其他机器人的 agent 不要加载本 skill。

## 7. 兜底

- 脚本不可用：退回 `grep`（限 1 次）+ `read` 前 60~80 行，仍然遵守预算。
- 库 / 小抄不可读：用 `FALLBACK_MEMORY` 顶上，并在回答里说明“Obsidian 库暂时读不到”。
- 未配置：先向用户确认路径并补全第 0 节，再继续。
